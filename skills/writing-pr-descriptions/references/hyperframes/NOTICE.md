# HyperFrames craft references

These files are copied unmodified from [HyperFrames](https://github.com/heygen-com/hyperframes) at tag `v0.8.138` (commit `0ca28db4f8671a2e2262594e03c566222d695920`), under the Apache License 2.0 in `LICENSE`. Copyright belongs to the HyperFrames authors.

They keep their upstream paths under `skills/`, so the links between them still work. The set is every document the change-reel skill reads, plus every document those link to.

Left out on purpose: HyperFrames' own pipeline documents (the brief contract, the script and storyboard formats, the storyboard recipe, the review loop and media-use). The change-reel build owns those steps. Frame presets and registry blocks are not copied: the skill reads them from the HyperFrames checkout that `reel/setup.mjs` makes.

Why they are here: later HyperFrames releases remove most of these documents from the repository.
